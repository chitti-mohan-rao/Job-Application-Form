# Job Application Form

A modern and responsive Job Application Form built using HTML, CSS, and JavaScript. The project features a clean glassmorphism-inspired user interface, animated background effects, client-side form validation, and a success message upon form submission.

## 🚀 Features

- Responsive design for desktop and mobile devices
- Modern glassmorphism UI
- Animated background glow effects
- Resume upload functionality
- Position application field
- Form validation using HTML5 and JavaScript
- Success message after successful submission
- Interactive hover and focus effects
- Clean and organized code structure

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Google Fonts (Poppins)

## ⚙️ How to Run the Project

1. Clone the repository:

```bash
git clone https://github.com/your-username/job-application-form.git
```

2. Navigate to the project folder:

```bash
cd job-application-form
```

3. Open `index.html` in your browser.

No additional installations or dependencies are required.

## 🎯 Form Validation

The form validates:

- Full Name
- Email Address
- Phone Number
- Position Applied For
- Resume Upload
- Message

Users are notified when the form is successfully submitted.
